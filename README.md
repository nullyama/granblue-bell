# グラブル 戦闘終了ベル

グラブルのマルチバトルのリザルト画面（URLが `/#result_multi/` で始まる部分を持つ画面）で鳴る、非公式のChrome拡張です。

## 導入

[ダウンロード（v1.0.9）](https://github.com/nullyama/granblue-bell/raw/refs/heads/main/downloads/granblue-bell-1.0.9.zip)を展開します。Chromeの `chrome://extensions/` でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを指定します。更新時は既存フォルダを上書きし、拡張機能とグラブルのタブを再読み込みしてください。

## 使い方

通知をオンにしたうえで、次の2つを設定します。

- **結果画面ですぐ鳴らす**：開いたときに1回。個別にオン・オフできます（初期値オン）。
- **リマインドまでの時間**：同じ画面に留まっていれば、開いてから設定時間後に1回。0分で無効、1〜1440分で設定できます（初期値3分）。画面移動・タブを閉じる・通知オフで取り消します。変更した分数は次の結果から適用します。

即時ベルをオフにして0分にすると、どちらも鳴りません。これまでの通知設定・分数・音量・音声は引き継ぎます。
